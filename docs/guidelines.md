
# What to Do — and What Not to Do

## ✔ Recommended

- keep supplementary files inside `suppliments/`
- maintain consistent units (µm, mJy)
- run scripts from the `gsed/` directory
- use version control (git)

## ✖ Avoid

```{warning}
- Do **not** rename folders without updating imports.
- Do **not** mix flux units (Jy vs mJy).
- Do **not** place nanometre/Ångström wavelengths without conversion.
- Do **not** manually edit installed package files.
