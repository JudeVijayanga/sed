#  PySpec

<center><b><font size="8"> A Python Package for Spectra Analysis </font></b></center>

PySpec is a Python-based package to perform different types of analysis on measured or calculated spectra. Our motto is:

> Science is spectral analysis. Art is light synthesis.
> $-$ [*Karl Kraus (writer), suggested by perplexity*](https://www.goodreads.com/quotes/7518101-science-is-spectrum-analysis-art-is-photosynthesis)

```{figure} logo.png
:align: center
```

PySpec features a set of integration routines which allows you to determine the area of your spectra. Additionally, you can sum up spectra, take their difference, interpolate between spectra, etc.

The software is under development, so new features are added on a regular basis.
